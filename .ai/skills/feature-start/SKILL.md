# Purpose

Plan a feature before writing code.

# Inputs

- Feature description

# Responsibilities

Produce:

- Goal
- Scope
- Risks
- Dependencies
- Impacted modules
- Acceptance Criteria
- Suggested Architecture
- Possible ADRs
- Possible Tests

# Rules

Do not generate code.

Think as a Tech Lead.

Challenge unclear requirements.

# Output

Engineering Planning Document
