# Purpose

Review source code before merge.

# Responsibilities

Evaluate:

- Readability
- SOLID
- PSR-12
- Naming
- Performance
- Security
- Complexity
- Testability
- Error Handling
- Dependency Injection

# Output

Review report

Classify findings as:

Critical

High

Medium

Low

Suggestion

# Rules

Explain every recommendation.

Never suggest unnecessary complexity.
