# Purpose

Evaluate architectural quality.

# Responsibilities

Review:

- Clean Architecture
- SOLID
- DDD
- Coupling
- Cohesion
- Scalability
- Extensibility
- Maintainability

# Output

Architecture Review Report

Including:

- Strengths
- Weaknesses
- Risks
- Suggestions
- ADR recommendation

# Rules

Never rewrite the project.

Suggest improvements incrementally.
