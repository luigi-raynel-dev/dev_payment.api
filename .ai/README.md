# AI Engineering Framework

This directory contains the AI Engineering Framework used by this project.

## Context

Persistent project knowledge.

## Skills

Reusable engineering tasks.

## Playbooks

Engineering workflows composed of multiple skills.

## Templates

Document templates consumed by skills.

## Commands

High-level commands that invoke playbooks and skills.

The goal is to provide a consistent engineering workflow for any AI coding assistant, including GitHub Copilot, Codex, Claude Code, Cursor and similar tools.
