# Start Sprint Playbook

## Objective

Prepare the next sprint.

## Steps

1. Read AGENTS.md.
2. Read AI Context.
3. Read current Roadmap.
4. Read latest CHANGELOG.
5. Read latest ADRs.
6. Read previous Sprint.
7. Generate Sprint Planning.
8. Validate Roadmap.
9. Suggest new ADRs if needed.

## Output

- Sprint document
- Updated roadmap
- Updated backlog
